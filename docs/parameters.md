# Parameters used in the model
Some parameters are used for generating the importation data while others are used to execute the ixa transmission model.

## Importation model parameters
The following parameters are necessary and sufficient for generating importation data using the `multinomial` methodology
- `symptomatic_reporting_prob`: The probability that individuals who are symptomatic are detected and reported as being infected with COVID-19
- `case_fatality_ratio`: The probability that individuals who are symptomatic will ultimately die of COVID-19
- `proportion_asymptomatic`: The proportion of individuals infected with COVID-19 who will never develop symptoms.

Generating importation data also depedns on user specification of importation model type at the national and state level.

## Transmission model parameters
The following parameters specified in the input parameter dictionary are only those relevant to transmission model behavior. 
Other parameters, such as report generation and maximum runtime do not affect model dynamics.
- `initial_prevalence`: The porportion of the population that is actively infectious at time t=0.0 in the model
- `imported_cases_timeseries`: File for importing infection attempts outside of local transmission and the initial prevalence.
- `infectiousness_rate_function.Constant.rate`: The rate at which infection attempts are generated by infected individuals during their infectious period
- `infectiousness_rate_function.Constant.duration`: The duration of the infectious period
- `settings_properties.Any.alpha`: The density-dependence scaling factor of the total infection attempt rate for a particular setting. See [transmission](transmission.md) for more details.
- `itinerary_ratios`: The default proportion of time indiividuals will spend in a specific setting category.
